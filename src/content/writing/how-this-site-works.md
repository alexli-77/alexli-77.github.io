This is a draft post. It appears when you run `npm run dev`, marked with a DRAFT badge, and never ships to the public site until `draft: true` is removed.

## Writing a new post

Run `npm run new "Your title"`, edit the Markdown file it creates, preview it locally, then push.

> Write locally, push to publish. No CMS, no database.

```bash
npm run new "What industrial search taught me about test oracles"
```
